## How to work
- Source of truth is this repo; `./install.sh` copies gate.py and the skill into ~/.claude and merges the hooks (idempotent).
- Tests use an isolated HOME and `USAGE_GATE_FAKE="<5h>,<weekly>"`; `USAGE_GATE_QUIET=1` silences notifications.
- Run gate commands in a response of their own (the hook rewrites them to add `--session`); arm, spawn and re-arm in separate responses.
- A paused session refuses its own edits; live tests that change the session file need the owner to run the command in a terminal.
- Never refresh the default login `Claude Code-credentials` (the CLI owns it); never print tokens.
- Telegram (D8/D9): `~/.claude/usage-gate/telegram.json` (mode 600: token, chat_id, optional machine); `gate.py telegram setup` (token on stdin) / `test`. Tests use `USAGE_GATE_TELEGRAM_API` (fake server), `USAGE_GATE_NO_OSASCRIPT=1`, `USAGE_GATE_FAKE_AGE=<s>`. Live check (arm just under current figure) still to do.
- Telegram commands (branch telegram-cmd): `gate.py telegram poll` (rate limit `USAGE_GATE_POLL_INTERVAL`, default 15 s; tests also use `USAGE_GATE_TICK` for loop sleeps), `gate.py listen`; state in `telegram-last.json` (last update id), `telegram-msgs.json` (message id -> session) and `telegram-polled`. Owner `/stop` and `/pause` set `manual` in the session file and hold until `/resume`/`/continue`. Live step 5 (phone check) still to do.
- Debug: `~/.claude/usage-gate/gate.log`, session state in `~/.claude/usage-gate/sessions/<id>.json`.
